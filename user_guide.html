User Guide

1. System Overview

The "IBAD Crystal Growth Process Analysis System" is designed to help users analyze various parameters during the crystal growth process, enabling better control and quality improvement. It offers a suite of tools including image analysis, parameter settings, anomaly detection, and data statistics review.

2. Main Functions

2.1. Analysis Buttons

Start Analysis

1. Select "Start Analysis" from the "Analysis" menu, or click the "Start Analysis" button on the main interface.

2. After selecting an image folder, the system will automatically load and start analyzing the images one by one.

Stop Analysis

1. Select "Stop Analysis" from the "Analysis" menu, or click the "Stop Analysis" button on the main interface.

2. You can pause the ongoing analysis process at any time by selecting "Stop Analysis".

Continue Analysis

1. Select "Continue Analysis" from the "Analysis" menu, or click the "Continue Analysis" button on the main interface.

2. If the analysis is paused, selecting "Continue Analysis" will resume the process.

2.2. Parameter Settings

Select "Set Parameters" from the "Settings" menu to open the parameter configuration window.

Image Processing Parameters

1. Image Coordinates: These parameters are used to crop the full-screen screenshot and isolate the RHEED image region. (x1, y1) and (x2, y2) represent the top-left and bottom-right corners of the target image within the screenshot. They are set to default values upon system launch but can be manually adjusted if needed.

2. Dark Spot Area Coordinates: These parameters are used to crop the rectangular dark spot area within the RHEED image. Similarly, (x1, y1) and (x2, y2) define the region. Manual adjustment is supported if the default crop is inaccurate.

Update Settings

Image Update Interval: This parameter controls how frequently the system refreshes and loads new images from the folder, in seconds. A smaller interval results in faster updates.

Threshold Settings

The system performs image analysis and parameter extraction on each crystal image. This component allows you to configure upper and lower thresholds for various parameters, adjusting the sensitivity of anomaly detection.

1. Crystal State Thresholds: You can manually set or reset to default the thresholds using sliders to determine how anomalies are detected based on parameter variations.

2. No Anomaly Prompt Threshold: Apart from detecting anomalies, the system also notifies the user when multiple consecutive images show no anomalies. This threshold controls how many normal images are required before such a notification is given.

Other Settings

1. File Path Settings: Select "Set File Path" from the Settings menu to open a file picker dialog and manually select the target image folder.

2. Comparison Image Path: Select "Set Comparison Image Path" to choose an image for comparison during the current session.

2.3. Image Display Interface

This interface shows the processed RHEED images. Bright spots detected by the algorithm are outlined in green, while dark spots are marked with green rectangles.

2.4. Plot Display Interface

The plot interface visualizes parameter trends, allowing users to intuitively observe subtle changes in the images during the experiment. Users can click "Save Plot" below the charts to save the parameter curves as images, which are stored under the plots directory, named by the system start time.

2.5. Prompt Display Interface

This interface displays the system's anomaly or no-anomaly prompts based on parameter changes. It contains two columns: "Time" for the image capture time and "Prompt" for anomaly/no-anomaly messages.

2.6. Statistical Analysis Interface

Select "Statistical Analysis" from the "Statistics" menu to open the statistics window. Users can filter previous logs based on start/end times, information types, and content for detailed review and analysis.

2.7. File Storage

1. Image Parameters: All extracted parameters for each image during a session are automatically saved in the params folder, named by the system start time, in CSV format.

2. Operation Logs: All system operations, events, and image status prompts are saved in the logs folder, also in CSV format, named by the session start time.

3. Parameter Plot Images: Saved manually by the user under the plots directory, organized by session start time, in PNG format.
